# 🚀 AleNedaj Backend

AleNedaj is a gas station tracking system that allows users to find gas stations, update traffic levels, and get directions.

## 📌 Features
✅ User authentication with email verification (JWT & JavaMail)  
✅ Admin dashboard to manage gas stations (CRUD operations)  
✅ Users can update traffic levels at stations  
✅ Integration with Mapbox for location & distance calculations  

## 🛠️ Tech Stack
- **Backend**: Spring Boot (Java), MongoDB, Mapbox API  
- **Frontend**: HTML, CSS, JavaScript  
- **Authentication**: JWT, JavaMail
